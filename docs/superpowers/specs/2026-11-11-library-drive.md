# Google Drive import into ShopPost Library

The production Library currently disables cloud import; demo connectors do not transfer real files. Implement a separate Drive grant, independent from YouTube, so a shop owner/manager can connect Drive and content staff can browse and import selected files. Use server-side OAuth authorization code with PKCE, encrypted credentials, one-use actor/shop-bound state, and explicit Drive read-only consent. Keep all provider tokens on the server. Import only after selecting real files; do not modify Drive. List with search and pagination. Export Docs/Sheets/Slides to DOCX/XLSX/PPTX. Bound each file to 50 MiB and streamed responses; display an accurate error on token revocation or missing configuration. Imported files remain in browser storage, with source and remote ID for duplicate detection; do not claim cloud synchronization. Dropbox/OneDrive/Email remain explicitly unsupported.

Approaches: download manually (already available); Google Picker with per-file grant (needs Picker API/key and client-side token); server-side read-only Drive API (chosen implementation default to keep tokens server-side and reuse Worker auth). Drive consent is broader than Picker and must be approved by the account holder at connection time. Deployment also requires enabling Drive API and registering the separate callback URL; do not claim a live connection from tests.
